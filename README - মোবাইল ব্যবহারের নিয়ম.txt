             মোবাইল ও পিসিতে PDF মেকার সফটওয়্যার - ব্যবহারের গাইড
════════════════════════════════════════════════════════════════════════════════

এই নতুন সফটওয়্যারের বিশেষ সুবিধা:
  ✅ Playwright বা Chromium ব্রাউজারের কোনো ঝামেলা নেই।
  ✅ সরাসরি মোবাইল (Android - Termux / Pydroid 3) এবং পিসিতে চালানো যাবে।
  ✅ স্বয়ংক্রিয়ভাবে ক্লিকেবল ইমেজ লিঙ্ক, লাল তারিখ, শিরোনাম ও বডি টেক্সট যুক্ত হবে।
  ✅ তৈরি হওয়া PDF গুলোর লোকেশন Excel ফাইলে (Column G) সেভ হয়ে যাবে।

────────────────────────────────────────────────────────────────────────────────
📱 পদ্ধতি ১: মোবাইলে Termux অ্যাপ দিয়ে চালানো (সবচেয়ে সহজ ও দ্রুত)
────────────────────────────────────────────────────────────────────────────────

১. মোবাইলে Play Store বা F-Droid থেকে "Termux" ইনস্টল করুন।
২. এই পুরো ফোল্ডারটি মোবাইলের ইন্টারনাল মেমোরি বা SD Card-এ কপি করে রাখুন।
৩. Termux ওপেন করে স্টোরেজ পারমিশন দিন:
      termux-setup-storage

৪. ফোল্ডারে ঢুকুন (উদাহরণস্বরূপ যদি Download ফোল্ডারে রাখেন):
      cd /sdcard/Download/"New folder (5)"

৫. প্রথমবার সেটআপের জন্য স্ক্রিপ্টটি চালান:
      bash setup_termux.sh

৬. সফটওয়্যারটি চালু করতে রান করুন:
      python mobile_pdf_maker.py

   👉 সাথে সাথে সব PDF তৈরি শুরু হয়ে যাবে এবং `pdf_output/output/` ফোল্ডারে সেভ হবে!

────────────────────────────────────────────────────────────────────────────────
📱 পদ্ধতি ২: মোবাইলে Pydroid 3 অ্যাপ দিয়ে চালানো (গ্রাফিক্যাল ইন্টারফেস)
────────────────────────────────────────────────────────────────────────────────

১. Google Play Store থেকে "Pydroid 3 - IDE for Python 3" ইনস্টল করুন।
২. Pydroid 3-এর Menu (☰) -> Pip -> Install ট্যাবে গিয়ে এই প্যাকেজগুলো ইনস্টল করুন:
      openpyxl pandas pillow xhtml2pdf requests
৩. ফোল্ডার থেকে `mobile_pdf_maker.py` ফাইলটি Pydroid 3-এ Open করুন।
৪. নিচের হলুদ Play (▶) বাটনে চাপুন।
   👉 স্ক্রিপ্ট চলতে শুরু করবে এবং কনসোলে প্রগ্রেস দেখাবে!

────────────────────────────────────────────────────────────────────────────────
💻 পদ্ধতি ৩: Windows PC-তে চালানো
────────────────────────────────────────────────────────────────────────────────

১. শুধুমাত্র `Run Mobile PDF Maker.bat` ফাইলটিতে ডাবল ক্লিক করুন।
২. স্ক্রিপ্টটি নিজ থেকেই সব প্রয়োজনীয় ফাইল প্রসেস করে PDF তৈরি করে ফেলবে।

────────────────────────────────────────────────────────────────────────────────
📋 EXCEL ফাইল ফরম্যাট (details2.xlsx)
────────────────────────────────────────────────────────────────────────────────

  Column A: Keyword (মূল কিওয়ার্ড, যেমন: sports highlight)
  Column B: Base Filename (ফাইলের নাম, যার শেষে ২ ডিজিট র্যান্ডম নাম্বার যুক্ত হবে)
  Column C: Body Text ফাইল বা পাথ (খালি থাকলে viral-body-templete থেকে র্যান্ডম নিবে)
  Column D: Image ফাইল বা পাথ (খালি থাকলে viral-image-templete থেকে র্যান্ডম নিবে)
  Column E: Title (বাধ্যতামূলক, শিরোনাম)
  Column F: Hyperlink URL (ইমেজে ক্লিক করলে যে লিঙ্কে যাবে)
  Column G: Output PDF Path (সফটওয়্যার স্বয়ংক্রিয়ভাবে এখানে তৈরি করা PDF-এর পাথ লিখে দিবে)

────────────────────────────────────────────────────────────────────────────────
📁 ফাইল ও ফোল্ডারের পরিচিতি
────────────────────────────────────────────────────────────────────────────────

  📄 mobile_pdf_maker.py          → মূল মোবাইল ও পিসি স্ক্রিপ্ট
  📊 details2.xlsx                → আপনার ডেটা ও ইনপুট এক্সেল শিট
  📁 viral-body-templete/         → আপনার টেক্সট টেমপ্লেট (.txt) রাখার ফোল্ডার
  📁 viral-image-templete/        → আপনার ছবি (.png, .jpg) রাখার ফোল্ডার
  📁 pdf_output/output/           → তৈরি হওয়া সব PDF এখানে জমা হবে
  📜 setup_termux.sh              → মোবাইলের টার্মাক্স সেটআপ স্ক্রিপ্ট
  🖱️ Run Mobile PDF Maker.bat     → পিসিতে ১-ক্লিকে চালানোর ফাইল
  📄 requirements.txt             → প্রয়োজনীয় পাইথন প্যাকেজ তালিকা
