            GitHub Pages-এ সফটওয়্যারটি সম্পূর্ণ লাইভ করার সহজ নিয়ম
════════════════════════════════════════════════════════════════════════════════

এই ওয়েব সফটওয়্যারটি GitHub Pages-এ লাইভ করলে আপনি পৃথিবীর যেকোনো মোবাইল,
ট্যাবলেট বা কম্পিউটার থেকে শুধু লিংকে ঢুকে কোনো কিছু ইনস্টল না করেই PDF বানাতে পারবেন!

────────────────────────────────────────────────────────────────────────────────
📌 ধাপ ১: GitHub-এ একটি নতুন Repository তৈরি করুন
────────────────────────────────────────────────────────────────────────────────
১. আপনার ব্রাউজারে github.com ওপেন করে আপনার অ্যাকাউন্টে Login করুন।
২. উপরে ডানপাশে '+' আইকনে ক্লিক করে "New repository" বেছে নিন।
৩. Repository name-এর ঘরে যেকোনো নাম দিন (যেমন: pdf-maker বা viral-pdf)।
৪. এটি অবশ্যই "Public" সিলেক্ট রাখবেন।
৫. নিচে "Create repository" বাটনে চাপ দিন।

────────────────────────────────────────────────────────────────────────────────
📌 ধাপ ২: ফাইলগুলো GitHub-এ আপলোড করুন
────────────────────────────────────────────────────────────────────────────────
১. নতুন তৈরি হওয়া পেইজে "uploading an existing file" অপশনে ক্লিক করুন।
২. আপনার `New folder (5)` ফোল্ডার থেকে এই ৪টি ফাইল ড্র্যাগ করে ছেড়ে দিন (বা Choose files দিন):
     • index.html
     • style.css
     • app.js
     • default_banner_base64.js
   (ঐচ্ছিক: titles_sample.txt ফাইলটিও দিতে পারেন)
৩. নিচে "Commit changes" বাটনে ক্লিক করুন।

────────────────────────────────────────────────────────────────────────────────
📌 ধাপ ৩: GitHub Pages চালু (Live) করুন
────────────────────────────────────────────────────────────────────────────────
১. আপনার Repository-এর উপরে "Settings" ট্যাবে ক্লিক করুন।
২. বামপাশের মেনু থেকে "Pages" অপশনে ক্লিক করুন।
৩. "Build and deployment"-এর নিচে:
     • Branch: "None"-এর বদলে "main" সিলেক্ট করুন।
     • Folder: "/ (root)" সিলেক্ট রাখুন।
৪. "Save" বাটনে ক্লিক করুন।

────────────────────────────────────────────────────────────────────────────────
🎉 ধাপ ৪: আপনার লাইভ লিংক পেয়ে গেলেন!
────────────────────────────────────────────────────────────────────────────────
১-২ মিনিট পর পেইজটি রিফ্রেশ করলেই উপরে আপনার লাইভ লিঙ্কটি দেখতে পাবেন, যেমন:
👉 https://your-username.github.io/pdf-maker/

এখন এই লিঙ্কটি আপনার মোবাইলের Chrome বা Safari ব্রাউজারে বুকমার্ক করে রাখুন!

────────────────────────────────────────────────────────────────────────────────
📱 মোবাইলে সফটওয়্যারটি যেভাবে ব্যবহার করবেন
────────────────────────────────────────────────────────────────────────────────
১. লিংকটিতে যান।
২. আপনার টার্গেট লিংক (যেখানে ভিউয়ার রিডাইরেক্ট হবে) দিন।
৩. "Title নির্বাচন" অপশনে গিয়ে আপনার টাইটেল সম্বলিত .txt ফাইল সিলেক্ট করুন
   (অথবা বক্সে সরাসরি টাইটেল লিখে দিন)।
৪. আপনার মোবাইল গ্যালারি থেকে পছন্দের ছবি বেছে নিন (অথবা ডিফল্ট ব্যানারই ব্যবহার করতে পারেন)।
৫. তারিখ অপশনে "পরের দিনের তারিখ" আগেই সিলেক্ট থাকবে (দরকার হলে কাস্টম তারিখ দিতে পারেন)।
৬. "PDF তৈরি শুরু করুন" বাটনে চাপ দিন।
৭. কয়েক সেকেন্ডেই সব PDF তৈরি হয়ে যাবে এবং নিচে এক ক্লিকে আলাদাভাবে বা ZIP ফাইলে ডাউনলোড করতে পারবেন!
